# SO2025 S2

## Descripción del Proyecto
Este repositorio contiene la documentación a los dos trabajos prácticos de la asignatura **Sistemas Operativos 2025**:

1.  **TP1: Linux From Scratch (LFS):** Construcción de un sistema Linux completo desde el código fuente.
2.  **TP2: Shell:** Desarrollo de un shell interactivo con funcionalidades personalizadas.


## Estructura del Repositorio



 - docs/               # Documentación del proyecto, planificación y guías.
 - imagenes/       #Imágenes para la Documentación LFS y SHELL
 - src/                 # Código fuente del TP2 (Shell) y scripts auxiliares para el TP1 (LFS).
 - tests/               # Scripts de prueba para validar el funcionamiento del Shell y del sistema LFS.
 - README.md            # Este archivo. Resumen y guía principal del proyecto.


# TP1 – Linux From Scratch

### Objetivo
Aprender y construir  un sistema Linux funcional compilando manualmente cada componente y documentar paso a paso dicha construcción.



# TP2 – Desarrollo de Shell

### Objetivo
Implementar una shell en C con funcionalidades básicas.

### Funcionalidades

- Parseador de comandos

- pwd

- rm

- echo

- exit
- ver_logs
- ver_errores
- help
- tutorial
